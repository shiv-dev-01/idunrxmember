# Idun Rx Member

Member portal for **Idun Rx**. Signed-in patients use this app for the account that belongs to Idun Rx.

The repository name is `idunrxmember` because this project is the member code for Idun Rx.

## Stack

- React
- Vite
- React Router
- Axios
- Tailwind CSS
- Auth0
- TypeScript
- Stripe

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/idunrxmember.git
cd idunrxmember
npm install
npm run dev
```

The dev server opens at http://localhost:5173.

## Scripts

| Command | What it runs |
| --- | --- |
| `npm run dev` | `vite` |
| `npm run build` | `tsc && vite build` |
| `npm run lint` | `eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 0` |
| `npm run preview` | `vite preview` |
